# workset_rates — «Ставки»

Модуль Odoo 19.0 для репозитория Odoo.sh `ERP-Ukraine/workset`. Здесь только устройство (модели, поля, экраны, права, автоматика,
плановые); данные — линии, их заказчики, периметр фирм, состав редакторов, исполнитель звірки, пороги частки — пишет инструмент штаба
через API.

## Что делает
- **Ставка** `workset.rate` — «працівник × замовник × Ставка з», одна на все фирмы, с историей пары. При сохранении «Вартість години»
  (`project.sale.line.employee.map.cost` + флаг ручной правки) ставится в строки карты проектов этого заказчика во всех фирмах периметра
  (только строки в EUR); пара без действующей ставки — строки обратно на `hourly_cost` карточки. Автоматика — методы `create` / `write`
  (поля-триггеры) / `unlink`, не `base.automation`.
- **А2**: строку карты создали или сменили в ней работника или проект — действующая ставка пары ставится сама.
- **Плановые** (`data/ir_cron.xml`): «Ставки: щодня» — 22:15 UTC (00:15 по Киеву зимой): будущие ставки становятся действующими,
  доли посредников сверяются; «Ставки: звірка» — понедельник 06:00 UTC, создаётся **выключенной**: запись «Звірка ставок» с разделами
  и одна задача To Do исполнителю.
- **Средние**: деньги ставки хранятся с `aggregator='avg'` — в строке каждой группы списка среднее, в подвале — среднее по списку;
  над списком и доской — ряд плиток итогов (`js_class` `workset_rates_list` / `workset_rates_kanban`, один вызов `rates_summary(domain)`);
  в шапке колонки доски — средняя «Частка WorkSET» колонки и полоса уровней доли (`progressbar`). Представление SQL `workset.rate.avg`
  («Середні») с 19.0.2 — без пункта меню (уровень A): действие `action_avg` остаётся для ссылок.
- **Левая панель**: «Робота» — все значения; «Лінія», «Замовник», «Фірми» — без пустых значений, линии и фирмы — по числу работающих
  (переопределение `search_panel_select_range` / `search_panel_select_multi_range`).
- **Посредники** (с М2): «Посередник» ставки — только договорённости модели `x_agent_client_deal` (почасовые `x_kind = hour`, состояния
  `zvirka`, `active`, по заказчику или линии); запасного «доля линии / вручную» М1 больше нет. Агент людей — участники `x_agent_people_member`
  почасовых договорённостей `x_agent_people_deal`. Моделей нет — 0 и «посередники не підключені». Дата поиска: действующая и будущая —
  сегодня (будущая — её «Ставка з»), прошлая — «Ставка до». Ночная «щодня» пишет, только если число изменилось. Имена моделей посредников —
  только в `models/agent_deals.py`. В звірке — раздел «Лінія з посередником, домовленості немає» по флагу линии «Очікується посередник».
- **Договор**: «У договорі» (`hr.version.hourly_wage`) есть только с `hr_payroll`; без него договор не сверяется (`contract_ok` = True,
  во вкладке «Контроль» — «модуля зарплат немає»).
- **Права**: привилегия «Ставки» в разделе кадров формы пользователя, группа «Редактор» — правка ставок и линий; чтение — кадры,
  бухгалтерия, администраторы проектов; удаление — только системный администратор; звірку создаёт только код (редактор ставит «Розібрано»).
  М2: уровни привилегии цепочкой — «Редактор» → «Бонуси офісу — перегляд» → «Правила ліній» (каждый включает предыдущий).

## Фонд работников, аренда авто, правка из списка (`19.0.3.0.0`)
- **Фонд працівників** `workset.rate.worker_fund_share` (хранимое, только чтение): сумма договорённостей модуля посредников вида
  `x_kind = worker_fund` по тому же правилу, что посредник (`calc.deal_fits`: с заказчиками — по заказчику, без — по линии; даты, живые
  состояния). Человеку с «Повна ставка» (`hr.version.workset_full_rate`, поле версии договора, права — кадры; в форме версии — рядом с
  почасовой ставкой, в форме работника — в строке «Тимчасово (не база)») на дату цепочки — `x_rate_full` договорённости (поля нет или 0 —
  `x_rate`). В «Посередник» не входит. Смена «Повна ставка» сразу пересчитывает ставки человека.
- **Оренда авто**: `workset.rate.rule.car_rent` (меняет только «Правила ліній», как доли) → `workset.rate.car_rent_share` из правила ставки;
  правка правила сразу пересчитывает его действующие и будущие ставки.
- Формула «За годину»: `W = Ц − Р − А_з − (А_л, если платит WorkSET) − фонд − аренда авто` (в «Фікс за місяць» — как посредник, не
  вычитаются). `_plan_at` отдаёт ещё `worker_fund_share` и `car_rent_share` (имя и подпись метода — прежние). Перенос `19.0.2 → 19.0.3`
  (`migrations/19.0.3.0.0/post-migrate.py`) пересчитывает цепочку действующих и будущих ставок.
- **Правка из списка**: карандаш у «Зарплата працівника», «Платять нам», «Посередник» — мастер `workset.rate.edit` («Нова ставка з дати» —
  новая ставка пары с даты через `_successor_vals`; «Виправити помилку» — число в той же ставке, причина обязательна и уходит в историю);
  «Посередник» → «лише цій людині» — `agent_own` + `agent_own_value` + `agent_own_reason` (цепочка берёт их вместо договорённостей,
  кнопка формы «За домовленістю» — назад), «для всієї домовленості» — карточка договорённости (если модель есть и её можно править).
  «Переговорити» — мастер `workset.rate.talk`: задача To Do на ставке (`mail.activity.mixin`) с цифрами человека; открытые — строкой в
  «Тривогах» «Огляду». Мастера — только редактору и администратору.
- **Працюють без ставки** (`_norate_pairs`): табели за 60 дней (от опорной даты «Працює») в проектах периметра с заказчиком без действующей
  ставки пары — в звірке «Проєкти без ставки» (строка «немає в карті проєкту», если строки карты нет) и тревогой «Огляду» (строка — новая
  ставка пары).
- **Зарплата по договору** `rates_wage_from_contract(ids=None, apply=False)` (только администратор; инструмент штаба `--wage-from-contract`):
  действующие ставки, где почасовая ставка текущей версии договора ≠ «Зарплата працівника» и дата версии позже «Ставка з» → новая ставка
  с даты версии; «Платять нам» по якорю (`calc.contract_raise_price`: тариф — та же, надбавка — + разница).
- Поиск по нехранимым Boolean (`has_raise`, `workset_is_worker`) — `calc.bool_search`: Odoo 19 приносит «in» / «not in» с `OrderedSet`.

## Цепочка цен (круг М2, `19.0.2.0.0`)
Формулы (за час, EUR, до ZUS и налогов на зарплату): `П = К − Ц`; «За годину» `W = Ц − Р − А_з − (А_л, если агенту людей платит WorkSET)`;
«Фікс за місяць» `W = фикс ÷ часы месяца` (`Ц = Р`); `Ч = W − Б`; «На руки зараз» `= Р + Н` (Н в W, Ч и карту проектов не входит).
Чистые функции — `models/calc.py`.
- **Загальна ставка** `workset.rate.rule` — правило линии (заказчик пуст) или тариф заказчика с датами: якорь (`markup` надбавка / `tariff`
  тариф), тип цены (`hour` / `fixed_month`), доли «знайшла лінія / знайшли ми», «Ціна нам», фикс за месяц, минимум, цена клиента с источником
  и датой, кто платит агенту людей. «Ставка до» и статус — код (А7). Ставка берёт самое точное правило на свою «Ставка з»; правка правила
  ставки **не** меняет — мастер `workset.rate.rule.apply` «Застосувати з дати» (просмотр «было → станет», «свои» — списком).
  Защищённое (правило линии целиком; у тарифа — якорь, доли, минимум, тип цены, фикс) меняет только группа «Правила ліній» — проверка в коде.
  Деньги правила, как и ставки, — с `aggregator='avg'`.
- **Ставка** `workset.rate` — новые поля: `rule_id`, `anchor`, `price_mode`, `fixed_month`, `is_own` + `own_reason` («Своя» ставится сама,
  если «Ціна нам» / тип / фикс правили руками и они ≠ правилу), `rule_price`, `client_price` (+ `client_price_source`, `client_price_date`,
  `client_price_manual`), `line_share`, `agent_client_share` + `agent_client_note` (посредник — только из договорённостей, адаптер
  `models/agent_deals.py`; `calc.agent_share_for`: договорённость с заказчиками — только по заказчику ставки, без заказчиков — по линии
  ставки, 06.11: две договорённости одного посредника на одной линии с разными заказчиками не складываются), `agent_people_share`, `people_agent_payer` + `people_agent_payer_manual` (как цена клиента: пока не правили
  руками иначе, чем в правиле, — за правилом и мастером), `month_hours`, `office_bonus` + `bonus_norm`, `net_share`,
  `net_level`, `found_missing`, `wage_source`, `contract_version_id`, `raise_ids`, `raise_now`, `wage_now`. Деньги — хранимые с `aggregator='avg'`.
  `price` теперь «Ціна нам» (не вычисляемое поле: число ставит цепочка); `agent_share` / `agent_source` М1 — справочно, в W не входят.
  `_plan_at(pairs, day)` — план на дату для «Прибутковості» (М3). `rates_summary(domain)` (полоса итогов) дополнительно отдаёт
  `avg_net` (сред. чистая доля), `below_min` (доля или чистая ниже минимума), `raises` (пары с временным изменением сегодня) и
  `contract_diff` (действующая ставка ≠ договору) — по тем, кто работает; плитки — «Сер. чиста частка», «Нижче мінімуму», «Тимчасових»,
  «Договір ≠ база» (красным / жёлтым при > 0), «Без частки» — только если > 0. `rates_link_rules(migration=False)` — ставки без
  «Загальної ставки» к правилам, появившимся позже (перенос, посев штаба): «Своя» с причиной, если цена ≠ правилу; только администратор.
- **Лінія** `workset.line` — `share_line_found`, `share_we_found`, `min_share` теперь только для чтения (из действующего правила линии),
  новые `rule_id`, `rule_ids`, `anchor`, `agent_expected` «Очікується посередник».
- **Бонус офісу** `workset.office.bonus` — € за час / € за работника в месяц / € за своих людей в месяц, заказчики, линии, люди, даты.
  Записи видят только группы «Правила ліній» (правка) и «Бонуси офісу — перегляд» (чтение); на ставке — итог.
- **Тимчасова зміна** `workset.rate.raise` (+ строки месяцев `workset.rate.raise.month`) — надбавка «+€ за час» или разовая сумма с–по, кто
  платит; без «По» не сохранить, две почасовые на одни дни — запрет, > 90 дней — предупреждение. Строка месяца → «До доплати» 1-го числа
  и на следующий день после «По»; на все такие строки — **одна** задача To Do исполнителю `workset_rates.check_assignee_uid`.
  «Виплачено» — только когда все строки с деньгами отмечены руками; месяц без часов — «Нічого доплачувати», изменение пересчитывается
  каждую ночь до `workset_rates.raise_grace_days` (45) дней после «По» (поздние табели дают доплату), потом — «Без годин».
  Мастер «Застосувати з дати»: ставки, начатые между «Ставка з» правила и датой применения, пересчитываются на месте; смарт-кнопка
  «Наслідують» и мастер считают одной функцией (дата — «Ставка з» правила, если она прошла, — сегодня).
- **Плановое «щодня»** дополнительно: статусы правил, цепочка действующих и будущих ставок (посредники, агент людей, часы, бонусы — цену и
  правило ставки ночь не меняет), месяцы временных изменений и задача доплат (набор строк изменился в тот же день — «Виплачено», новое
  изменение — переписывается та же задача, если она создана сегодня по Киеву — по дате создания, не по сроку; о новых строках в ней
  исполнителю — сообщение в истории изменения), догон А6 и страж «вгору і назад».
- **А6 «договір → база»** (`models/hr_version.py`, `_inherit = 'hr.version'`): версию договора создали («нова з дати») или изменили
  `hourly_wage`, `wage_type`, `date_version`, `active`, `workset_temporary` → в парах, где эта карточка — карточка договора (как «У договорі»
  М1), ставка на дату версии получает «На руки» из договора: то же «На руки» — только `contract_version_id`; та же «Ставка з» — новое
  «На руки» в ней; иначе — новая ставка с даты версии (копия предыдущей, `source = contract`, `wage_source = contract`), цена — по якорю
  (надбавка — растёт, тариф — та же, частка падает, «Своя» — та же, фікс — = на руки), запись в историю ставки. Не берёт: карточку вне
  периметра, не почасовой договор или ставку выше `workset_rates.max_hourly_wage`, версию раньше первой ставки пары. `hourly_wage` /
  `wage_type` — поля модуля зарплат (Enterprise), читаются мягко (`workset.rate._contract_of`); без него А6 ничего не делает.
  **Выключатель** — параметр `workset_rates.a6_mode`: нет параметра (или мусор) — `off`, А6 не делает ничего (так сразу после обновления);
  `dry` — сохранение договора ничего не делает, ночь только считает: в итоге `rates_daily` ключ `a6_would` и фраза «створив би ставок N»
  в `message` и в журнале — число владельцу до включения (раздел 9); `on` — действует. Ошибка проверки ставки внутри А6 (дубль на дату)
  не глотается: договор не сохраняется с `UserError` «Ставки: … — договір не збережено, напишіть редактору ставок …».
  **Ставка идёт за своей версией** (`_contract_follow`): ставки с `contract_version_id` = версия и `wage_source = contract`, если версию
  отметили «Тимчасово», архивировали, перенесли её дату, карточка ушла из периметра или ставка версии больше не годится: созданные А6
  (`source = contract`) — в архив; внесённые иначе, где А6 лишь переписал «На руки» на ту же дату, — назад прежнее «На руки»
  (`wage_before_contract`, `wage_source_before` запоминаются при переписывании; нет числа — «Перевірити» с причиной). Причина — в истории
  ставки; пара пересчитывается (А1), перенос даты — новая ставка с новой даты. Если на «Ставка з» есть **другая действующая версия**
  договора человека (не «Тимчасово», карточка в периметре, почасовая и ≤ порога; например, версия другой карточки, которая переписала
  ставку на ту же дату), — ставка не уходит в архив, а возвращается к ней (`_contract_fallback`, `calc.contract_fallback`: самая новая по id).
  В итоге `_contract_to_base` / `rates_daily` — отдельные счётчики `archived` (в архив), `restored` (возвращено «На руки»: прежнее или из
  другой версии) и `check` («Перевірити»); `message` ночи называет `restored` и `check`, если они > 0. «Версія договору» ставки меняется только на более новую
  версию (дата, затем id), а у ставки «з договору» с другой датой — никогда: она принадлежит версии, которая её создала
  (`calc.contract_link`); ночь без изменений даёт «пов'язано 0».
  Поле `hr.version.workset_temporary` «Тимчасово (не база)» (`copy=False`, `groups` кадров — через `_inherits` оно и поле работника):
  строка во вкладке «Payroll» формы работника и в каждой форме самой версии (`_get_view`: в первый `sheet` перед вкладками — внешних id
  видов версии модуль не знает); версия не меняет ставку, временное изменение пары на её дату получает `version_id`. Ночью — догон
  (версии, изменённые мимо ORM) и страж: версия подняла ставку, следующая в пределах `workset_rates.temp_window_days` вернула, возврат не
  раньше первой ставки пары, отметки и временного изменения нет → ставкам обеих версий «Перевірити» с причиной (снимается, когда
  совпадение пропало; ставку с чужой причиной «Перевірити» страж не трогает). Страж работает при любом режиме А6.
- **Вкладка «Контроль»** — на языке смотрящего: `_control` пишет хранимые `control_html_uk` и `control_html_ru`, отпечаток — от
  обеих (правка только русского словаря тоже переписывает вкладку); `control_html` — вычисляемое по языку контекста. Старый хранимый столбец `control_html` после обновления пуст.
- **Поля на `hr.employee`** (`workset_rate_count`; `workset_temporary` через `_inherits` версии) — с `groups='hr.group_hr_user'`: поле
  работника без пары на `hr.employee.public` без групп роняет тест `hr` `test_employee_fields_groups`; смарт-кнопка — тем же группам.
- **Звірка М2** (та же запись, одна задача): «Договір ≠ база» (молчит, когда договор = «На руки» + действующая надбавка пары, или версия
  отмечена «Тимчасово», а надбавки нет),
  «Договір не погодинний або більший за N €/год», «Тимчасова версія без тимчасової зміни», «Вгору і назад без позначки», «Нижче мінімуму»
  (частка > 0, но ниже минимума; задач модуль не ставит), «Тимчасові зміни» (кончается ≤ 3 дн., до доплати, без годин), «Частка WorkSET
  не за правилом» (частка ≤ 0; «Своя» — только если общая ставка сменилась > 14 дней назад), «Загальної ставки немає», «Хто знайшов не
  вказано»; «Лінія з посередником, домовленості немає» — М1; «Лінія з надбавкою без правила житла» (М2c: линия с якорем «надбавка» и
  действующими ставками, а правила жилья на сегодня нет; тарифные молчат).
- **Житло лінії** `workset.line.housing` (М2c, раздел 3.13) — как линия считает жильё людей: `kind` (`hour_deduction` «години житла × €»,
  `payment_buffer`, `invoice_buffer`, `customer_deducts`, `none`), `amount` + `amount_unit` (`hour`, `month`, `day_person`, `pct`),

## Установка
1. Папку модуля — в репозиторий Odoo.sh (ветка копии → проверка сборки и тестов → `main`); помощник штаба `tools/odoo_sh_push.js`.
   С уровня B модуль зависит от `web_gantt` (Enterprise, на копии 20 установлен): без него модуль не установится.
2. `node tools/odoo_workset_rates.js --target copy --install --apply` — обновить список модулей и установить (обновить) модуль.
3. `node tools/odoo_workset_rates.js --target copy --seed --apply [--editors <id,…>]` — линии и заказчики, параметры (посев М1).
   С 19.0.2 доли линии — из «Загальної ставки» линии (только чтение): `--seed` их не пишет.
4. Перенос ставок — `node tools/odoo_rates_migrate.js` (уже на новые имена); `--seed-overrides`.
5. `--seed-m2` — правила линий и тарифы заказчиков, бонусы офиса, жильё линий, группы; ставки без правила — к правилам (`rates_link_rules`).
   `--a6-mode dry` — первая ночь А6 только считает; затем `--check-cron on`.
6. `--verify` — модуль, виды (с М2), меню, права, группы, параметры, плановые, А6 вхолостую.

### Перенос 19.0.1 → 19.0.2 (`migrations/19.0.2.0.0/`, только при обновлении; свежая установка 19.0.2 сюда не заходит)
- `pre-migrate.py` — доли линий М1 («Знайшла лінія», «Знайшли ми», «Мінімум частки») во временную таблицу `workset_rates_m1_line_shares`:
  с 19.0.2 эти поля вычисляются из правила линии.
- `post-migrate.py` — для каждой линии с долями М1 — «Загальна ставка» уровня линии: якорь «Надбавка» (М1 считал цену «на руки + доля»;
  тариф ставит посев штаба), «Ставка з» — самая ранняя «Ставка з» её ставок, источник «Перенесено з проєкту», «перенос з М1»
  (`calc.migration_line_rules`); линия без долей — без правила. Затем ставки (`workset.rate.rates_link_rules(migration=True)`):
  «На руки з» — «Перенос» (кроме «Договір»), «Своя» — если Ц (тип, фікс) ≠ правилу на «Ставка з», с причиной «було: частка агента N
  (до посередників)» (ручная доля посредника М1) или «перенос з М1: ціна ≠ загальній ставці (за правилом X)» (`calc.migration_rate_vals`);
  ланцюжок без автоматики А1 — карта проектов и заказы не меняются. Временная таблица удаляется.
- Параметр `workset_rates.a6_mode` не создаётся: нет параметра — А6 выключено (`off`); включает инструмент штаба (`--a6-mode`).
- Бизнес-чисел в миграции нет — только перенос того, что уже в базе. Тест — `test_m2c2_migration_from_m1` (Odoo) и
  «calc М2c-2» в `tools/tests/odoo_workset_rates_module.test.js`.
